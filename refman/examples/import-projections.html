Record import

Gives short names to record projections applied to a given record instance ("import" a record instance by naming its applied projections).

Usage examples:

Record r T (t : T) := Build { p1 : nat; p2 : t = t; _ : p2 = refl_equal; }.
r is defined p1 is defined p2 is defined
Section test.
Variable x : r nat 3.
x is declared
import.projections x.
Print p2.
Notation p2 := (p2 nat 3 x)
Check p1 : nat. (* check p1 is already applied to x *)
Top.p1 nat 3 x : nat : nat
End test.
Fail Check p1 : nat. (* the abbreviation is gone *)
The command has indeed failed with message: The term "p1" has type "forall (T : Type) (t : T), r T t -> nat" while it is expected to have type "nat".
Check p1 : forall (T : Type) (t : T), r T t -> nat. (* p1 points again to the original projection *)
