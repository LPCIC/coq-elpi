Reflexive tactic

Builds a reflexive tactic solving equalities in a monoid. We use Elpi to:

  • reify an expression into a syntax tree

  • query a Db of known monoids

  • call a few Ltac primitives in order to apply the correctness theorem

Note

This example depends on Rocq's Stdlib theories (and ssreflect), unlike the other cookbook examples.

This module contains the reflexive normalizer and its correctness proof (not the point of this demo -- the proofs are not the interesting part):
