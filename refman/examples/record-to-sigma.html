Record to sigma

A command that de-sugars a record type to iterated sigma types, suggested by M. Maggesi for the UniMath library.

Elpi Export UM.expand.

From now on UM.expand is a regular command taking as the only argument a record declaration:

UM.expand Record foo := mk_foo { f1 : Type; f2 : f1 -> Type; f3 : forall t : f1, f2 t -> bool }.
foo is defined mk_foo is defined
Print foo.
foo = {f1 : Type & {f2 : f1 -> Type & forall t : f1, f2 t -> bool}} : Type
Print mk_foo.
mk_foo = fun (f1 : Type) (f2 : f1 -> Type) (f3 : forall t : f1, f2 t -> bool) => existT (fun f4 : Type => {f5 : f4 -> Type & forall t : f4, f5 t -> bool}) f1 (existT (fun f4 : f1 -> Type => forall t : f1, f4 t -> bool) f2 f3) : forall (f1 : Type) (f2 : f1 -> Type), (forall t : f1, f2 t -> bool) -> foo Arguments mk_foo f1%_type_scope (f2 f3)%_function_scope
