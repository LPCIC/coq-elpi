Record expansion

Sketches a procedure to translate a term abstracted over a specific record to a term abstracted over the components of that record.

Example:

Record r := mk { proj1 : T1; proj2 : T2 }.
Definition f (x : r) := Body(proj1 x,proj2 x).

is expanded to:

Definition f1 v1 v2 := Body(v1,v2).

And recursively, if g uses f, then g1 must use f1...

The idea is to take f, replace (x : r) with as many abstractions as needed in order to write mk v1 v2, then replace x with mk v1 v2, finally fire iota reductions such as proj1 (mk v1 v2) = v1 to obtain f1.

Then record a global replacement f x = f1 v2 v2 whenever x = mk v1 v2.

Note

The expand predicate below is used before all of its clauses are known (new ones are added at runtime via coq.elpi.accumulate), so Elpi's static analysis cannot fully check it and emits a benign elpi.flex-clause warning. As the tutorials already do for elpi.linear-variable, it is silenced with Set Warnings.
